# Route Lens 1.3.1 前端说明

## Popup 与页面侧栏

浏览器工具栏 Popup 有“状态”和“外观”两个页签。状态页显示请求模型、服务器报告模型字段、两者比较结果及记录详情；这些字段只说明页面可观察到的值，不能证明底层执行模型或回答质量。

外观页的滑块范围与 `service-worker.js` 的归一化范围一致：

| 设置 | 范围 | 默认值 |
|---|---:|---:|
| 侧栏宽度 | 64–112 px | 72 px |
| 侧栏高度 | 40–90% | 75% |
| 垂直位置 | 0–100% | 58% |
| 字号 | 9–14 px | 10 px |
| 背景不透明度 | 55–100% | 92% |

主题有跟随系统、浅色、深色三种。请求模型、服务器报告模型和状态可分别隐藏。恢复默认按钮只提交外观设置，不会清除记录、采集模式或其他偏好。设置通过扩展消息写入本地扩展状态，并由内容桥接更新页面侧栏。

侧栏由 `extension/content/bridge.js` 渲染在 Shadow DOM 内，条内内容可滚动。侧栏请求宽度会按视口宽度收窄；高度受视口底部留白限制。视口不超过 1120 px 时，桥接代码会给页面 `body` 设置右侧边距，数值使用收窄后的侧栏宽度。该规则是对宿主布局的适配尝试，不保证覆盖 ChatGPT 未来或所有视口布局。

## 本地浏览器验收

运行：

```sh
npm test
npm run check
node scripts/ui-preview.mjs
```

预览脚本在隔离的无头 Chrome/Chromium 中打开本仓库的 Popup 文件和合成聊天页。侧栏直接加载本仓库的实际 `extension/content/bridge.js`，不再使用手写侧栏替代品。合成运行时通过本地存储和 BroadcastChannel 提供状态，并模拟 Popup 与内容桥接间的扩展消息。

脚本检查滑块端点与后台范围、设置消息及侧栏同步、明暗主题与系统主题、三个显示开关、默认外观恢复、关闭再打开后的持久值、超长模型名滚动，以及侧栏与合成输入框的矩形交集。它使用合成模型记录；没有加载 `page-hook.js` 或扩展 service worker，也没有安装扩展、连接 ChatGPT 或发送网络请求。因此，截图只验证实际桥接代码在本地页面夹具中的表现，不能证明 ChatGPT 实际布局中的输入框永远不会被遮挡。

默认截图目录为 `outputs/route-lens-1.3.1/previews/`。可以用 `--out-dir <路径>` 或 `ROUTE_LENS_PREVIEW_DIR` 指定其他目录。Chrome/Chromium 从本机候选路径或 `PATH` 探测；也可用 `CHROME_PATH` 指定可执行文件。每次运行生成的文件名由 `scripts/ui-preview.mjs` 的 `screenshotNames` 列出。目录内其他预存文件不属于本次验收证据。

本版本未在真实 ChatGPT 会话中验证，合成页面结果不能证明真实站点兼容性。
